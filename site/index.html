Search搜尋

Describe it, don’t remember it用描述的，不用記關鍵字

Type what the email was about, the way you’d say it to someone. MailSift runs your words through an embedding model on your Mac (EmbeddingGemma 2, via Core ML) and through a keyword index at the same time, then merges the two lists. The meaning side finds mail across languages: ask in Chinese, get the English or Japanese mail. 輸入那封信大概在講什麼，像跟人描述一樣。MailSift 同時用 Mac 上的嵌入模型（EmbeddingGemma 2，透過 Core ML）和關鍵字索引搜尋，再把兩份結果合併。語意這邊可以跨語言：用中文問，英文、日文的信也找得到。

  • Search works while indexing is still running: keywords cover every message right away, and meaning is added newest mail first索引還沒跑完就能搜：關鍵字立刻涵蓋所有信，語意索引從最新的信開始補
  • Each result shows how it was found: meaning, keyword, both每筆結果標出怎麼找到的： 語意、 關鍵字、 兩者都有
  • The model downloads once, inside the app模型在 app 裡下載一次就好

AI side panelAI 側欄

It proposes. You decide.它提議，你決定

Press ⌘J and ask about your mail with Claude Code or Codex, using the login you already have; there is no API key to set up. The agent searches and reads through MailSift, but it cannot change anything on its own. To clean up, it lists each message with a checkbox and a reason. Untick what you want to keep, then confirm. Reply drafts open in Mail for you to edit and send. 按 ⌘J，用你已經登入的 Claude Code 或 Codex 問你的信，不用另外設定 API 金鑰。它透過 MailSift 搜尋、讀信，但不能自己動你的信。要整理時，它把每封信列出來，附上勾選框和理由；把想留下的取消勾選，再按確認。回信草稿會在「郵件」裡打開，由你改完再寄。

Claude Code Codex

Senders寄件者

Clean up by who sends it照寄件者一次清掉

Senders lists everyone who mails you, ranked by how many messages they’ve sent, with the account and the latest date. Select a few and move all of their mail to Trash at once, after a confirmation that shows the count. Or switch to the map, where senders sit near others who write about similar things. 「寄件者」列出每個寄信給你的人，依封數排序，附上帳號和最新一封的日期。選幾位，確認過封數後，就能把他們的信一次移到垃圾桶。也可以切到地圖，內容相近的寄件者會排在一起。

Reads like a mail client也是一個順手的讀信工具

Every mailbox, by date所有信箱，依日期分組

Inbox, Flagged, Archive, Spam and Trash across all your Mail accounts, grouped into today, yesterday, this week, this month and earlier. Flagged mail stays pinned on top of the Inbox.所有帳號的收件匣、旗標、封存、垃圾郵件和垃圾桶，分成今天、昨天、本週、本月、更早。有旗標的信固定在收件匣最上面。

Actions go through Mail動作交給「郵件」執行

Archive, Trash, flag, mark read or unread and mark as junk are carried out by Mail.app, so your accounts and servers stay in sync the usual way.封存、移到垃圾桶、加旗標、標為已讀未讀、標為垃圾郵件，都交給「郵件」App 執行，帳號和伺服器照原本的方式同步。

Reply and forward in Mail在「郵件」裡回信、轉寄

Reply, reply all, forward and ⌘N open Mail’s own compose window. MailSift never sends mail.回覆、全部回覆、轉寄和 ⌘N 都會打開「郵件」自己的撰寫視窗。MailSift 不會替你寄信。

Attachments附件

Open an attachment, show it in Finder or save it to Downloads, right from the message.在信裡直接打開附件、在 Finder 中顯示，或存到「下載項目」。

For developers給開發者

Give your own agent your mail讓你自己的 agent 也能查信

The app ships a mailsift command-line tool that uses the same index. Every command takes --json, and anything that changes mail is a dry run until you add --yes. Run it as an MCP server and Claude Code, Codex or any MCP client can search, read threads and list senders. Changes take two steps there too: a preview with the exact count, then the action on those ids only. The Index pane shows the exact commands with the path filled in. App 內附 mailsift 指令列工具，用的是同一份索引。每個指令都能加 --json；會改動信件的指令，沒加 --yes 都只是試跑。把它當 MCP 伺服器跑，Claude Code、Codex 或任何 MCP 用戶端都能搜尋、讀整串對話、列出寄件者。改動一樣分兩步：先預覽確切封數，再只對那些信執行。「索引」頁面會列出填好路徑的完整指令。

Your mail stays on your Mac信留在你的 Mac 上

MailSift reads Mail’s local data directly and keeps its index on your Mac. It uploads nothing and has no account or server. MailSift 直接讀「郵件」在本機的資料，索引也存在你的 Mac 上。它不上傳任何東西，沒有帳號，也沒有伺服器。

When it goes online什麼時候會連網

  • Model download. Once, from Hugging Face, the first time the model is needed.下載模型。第一次需要模型時，從 Hugging Face 下載一次。
  • Remote content in mail. Images and fonts in a message load from the sender’s server, which lets the sender see your IP and when you read it. This is on by default; turn it off in Settings and load images per message instead.信裡的遠端內容。信件中的圖片和字型會從寄件方的伺服器載入，對方因此看得到你的 IP 和讀信時間。預設是開的；可以在設定裡關掉，改成每封信個別載入。
  • AI side panel. When you use it, the mail the agent reads goes to Anthropic or OpenAI through your own Claude Code or Codex.AI 側欄。使用時，agent 讀到的信會透過你自己的 Claude Code 或 Codex 送到 Anthropic 或 OpenAI。

Full Disk Access完整磁碟取用權限

Mail’s data lives in a protected folder, so MailSift needs Full Disk Access. That’s also why it’s distributed outside the App Store. The source is on GitHub if you want to check what it does with that access.「郵件」的資料放在受保護的資料夾裡，所以 MailSift 需要完整磁碟取用權限，這也是它不在 App Store 上架的原因。想確認它拿這個權限做了什麼，原始碼都在 GitHub 上。
